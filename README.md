# To-Do List GUI Application (Java Swing)

A desktop To-Do List app built with Java Swing.

## Features
- Add tasks through a graphical interface
- Remove tasks by task number
- Input validation with warning messages for empty or invalid entries

## Technologies
Java, Swing (JFrame, JButton, JTextField, JTextArea, GridLayout)

## How to run
javac ToDoList.java
java ToDoList
